📦 导出 / 试玩

部署到 GitHub Pages：把 index.html（游戏）和 build.html（本编辑器）放进仓库同一目录，开启 Pages 即可。
两个页面用相对路径互相跳转，游戏顶栏 / 侧栏的「🗺 编辑器」按钮会打开本页，本页「🎮 返回游戏」回到游戏。
试玩会把地图写进浏览器 localStorage 并以 ?fromeditor=1 打开游戏（不覆盖自动存档）。
手动加载：左侧「🧩 模组」→ 选 .js 文件 → 地图列表选择新地图。
